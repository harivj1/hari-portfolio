# Hari Cybersecurity Portfolio

A Vite + React + TypeScript portfolio inspired by a Kali Linux / cyberpunk desktop.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Customize

Edit `src/App.tsx` to change:
- Name / headline
- Project descriptions
- Certifications
- Skills
- GitHub / LinkedIn / email links

The hero artwork is in:

`src/assets/kali-hero.svg`

## Build

```bash
npm run build
```
